# 依赖及发布范围

此仓库的首批源码对应已封存版本的新增模块与固件主体，不是完整板级工程。未授予第三方文件新的许可证，也不以本仓库的公开状态推定原供应商授予了再发布许可。

当前未发布：

- Efinity 工具、许可证和厂商 IP 库。
- MIPI、DDR、HDMI、SoC 生成物及基础板级参考工程。
- `sc2210_table.inc`：由参考工程寄存器 ROM 转换的传感器配置表；来源和再发布许可待核对。`firmware/sc2210.c` 仍引用它，未以空表替代。
- 基础参考工程中包含 `CONFIDENTIAL IN CONFIDENCE` / CrazyBingo 授权限制声明的文件，例如 `lcd_driver.v`、`CMOS_Capture_RAW_Gray.v`、`VIP_RAW8_RGB888.v`。保留本地原始声明，未纳入此次公开提交。
- 完整 bitstream 和完整源码压缩包：随依赖许可范围确认后决定公开或通过赛事允许的方式提供。

用户需要合法取得相应开发板参考工程及 Efinity 环境。仅安装工具或下载本仓库，当前不足以直接重建整板 bitstream。目录未附完整项目配置，因此也不把单个 RTL 文件编译通过称为整板复现。

后续应补充精确的参考工程版本、取得途径、缺失文件清单和集成步骤；未经核对，不删除原版权头、不把整包套为 MIT 等许可。赛事“全部代码 RAR”交付和 GitHub 公开交付分别核对，不能把这份源码子集当成已经完成全部代码提交。
